常見問題與解答 (FAQ)

Q1. 轉換後的照片會降低畫質嗎？

A: 轉換為 PNG 採用的是無損壓縮編碼（Lossless），完全保留原始色彩與清晰度，絕不犧牲任何畫質細節。

Q2. 可以轉成 JPG 或 WebP 嗎？

A: 可以！在視窗版「轉換設定」中，您可以自由在 PNG、JPG 與 WebP 之間切換。

Q3. 需要安裝 Python 嗎？

A: 不需要！直接下載發行版的獨立 .exe 檔案，雙擊即可直接在任何 64 位元 Windows 電腦上運行。
